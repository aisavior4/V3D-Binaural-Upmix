# V3D-Binaural-Upmix
Stereo → Binaural spatial upmix engine for mobile video and headphone listening (V3D project)
V3D is a mobile video spatial audio engine for transforming smartphone video audio into headphone-friendly spatial / binaural output.

## Project Direction

V5.x = Stereo Enhancement  
V6.x = Spatial Reconstruction for mobile video

Current focus:
- Camera perspective
- Front / Rear distance
- Body preservation
- Width support
- Elevation is postponed

## Core Presets

- ZOOM: close / focused / front
- WIDE: wider ambience
- DEEP: farther / darker / more immersive
